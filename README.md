# 당근마켓 검색·알림 봇 (깃허브 액션판)

오라클 서버 없이 **깃허브가 직접 돌리는** 당근마켓 봇입니다.
서버 관리·재시작·메모리 부족(OOM) 걱정이 없습니다.

## 기능 2가지

| 기능 | 설명 | 실행 방법 |
|---|---|---|
| **알림봇** | `keywords.json` 의 키워드를 **전국에서 매시간 자동 검색**, 새 매물만 텔레그램 알림 | 자동 (매시 정각) |
| **즉석검색** | 키워드를 그때그때 넣어 전국/지역 검색 | 깃허브 화면 버튼 |

---

## 처음 한 번만 — 설정 (5단계)

### 1. 깃허브에 올리기
이 폴더를 깃허브 저장소(repository)로 올립니다.
> **공개(public) 저장소로 만드세요.** 비공개는 무료 실행시간이 한 달 33시간뿐이라
> 전국 매시간 검색이 금방 초과됩니다. 공개는 무제한 무료입니다.
> 비밀 토큰은 아래 Secrets(금고)에 따로 넣으므로 공개해도 노출되지 않습니다.

### 2. 비밀정보(토큰) 넣기 — 가장 중요
저장소 → **Settings → Secrets and variables → Actions → New repository secret**
아래 4개를 등록합니다. (노션을 안 쓰면 뒤 2개는 생략 가능)

| 이름 | 값 |
|---|---|
| `TELEGRAM_TOKEN` | 텔레그램 봇 토큰 |
| `TELEGRAM_CHAT_ID` | 알림 받을 채팅 ID |
| `NOTION_TOKEN` | 노션 토큰 (선택) |
| `NOTION_DATABASE_ID` | 노션 DB ID (선택) |

> ⚠️ 옛 코드에 토큰이 그대로 적혀 있었습니다. 한 번이라도 외부에 노출됐다면
> 텔레그램·노션 토큰을 **재발급**받아 위에 새 값으로 넣는 것을 권장합니다.

### 3. 액션 켜기
저장소 **Actions** 탭 → 안내가 나오면 워크플로우 실행을 허용합니다.

### 4. 지역코드 먼저 수집 (1회 필수)
Actions 탭 → **지역코드 수집** → `Run workflow` 클릭.
20~40분 뒤 `region_map.json` 이 채워집니다. 이게 있어야 '전국'이 동작합니다.
(이후 매주 월요일 새벽 자동 갱신)

### 5. 감시할 키워드 정하기
`keywords.json` 파일을 열어 원하는 키워드로 수정합니다.
```json
[
  "아이폰15",
  "다이슨 청소기"
]
```
저장(커밋)하면 다음 정각부터 그 키워드로 감시합니다.

## 평소 사용법

### 알림봇 (자동)
아무것도 안 해도 됩니다. 매시 정각에 깃허브가 알아서 전국을 검색하고
**새로 올라온 매물만** 텔레그램으로 보냅니다.
- 첫 실행은 알림 없이 현재 매물을 기록만 합니다 (도배 방지).
- 키워드를 바꾸고 싶으면 `keywords.json` 만 수정하면 됩니다.

### 즉석검색 (수동)
Actions 탭 → **당근 즉석검색** → `Run workflow` →
키워드 입력 (지역은 비우면 전국) → 초록 버튼.
결과는 텔레그램으로 오고, 표(CSV)는 실행 결과 화면 아래 `검색결과` 에서 받습니다.
> 휴대폰 브라우저에서도 깃허브 Actions 페이지로 똑같이 실행됩니다.

## 알아둘 점

- **검색 주기 바꾸기**: `.github/workflows/watch.yml` 의 `cron: '0 * * * *'`
  (`0 */2 * * *` = 2시간마다). 전국은 한 번에 15~40분 걸립니다.
- **차단 위험**: 깃허브 서버에서 당근에 많은 요청을 보내므로, 너무 잦은 주기는
  당근 쪽에서 막힐 수 있습니다. 매시간 정도가 무난합니다.
- 키워드가 많을수록 검색이 오래 걸립니다. 전국 감시는 3~5개 이내를 권장합니다.

## 파일 설명

| 파일 | 역할 |
|---|---|
| `daangn_search.py` | 검색·알림 본체 |
| `keywords.json` | 알림봇이 감시할 키워드 목록 |
| `region_map.json` | 전국 지역코드 (자동 생성·갱신) |
| `seen.json` | 이미 알림 보낸 매물 기록 (중복 방지, 자동 관리) |
| `.github/workflows/` | 깃허브 자동 실행 설정 3개 |
